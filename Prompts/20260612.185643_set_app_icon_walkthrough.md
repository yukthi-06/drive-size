# Walkthrough - Custom App Icon Configuration

We have configured the application to use the custom icon image `app-icon.png` located in the root folder of the project.

## Changes Made

### 1. Manifest Configuration (`app/src/main/AndroidManifest.xml`)
- Updated the `android:icon` attribute of the `<application>` tag from the system fallback default to reference `@drawable/ic_launcher`.

## Manual Action Required
Because command execution was restricted, please perform the following step:
- Copy the file **`app-icon.png`** from the root folder of the project.
- Paste it into the folder **`app/src/main/res/drawable/`**.
- Rename it to **`ic_launcher.png`**.

Once done, the compiler will bundle the custom image as the official application icon during the build process.
