# Documentation Guideline - New MD File For Every Prompt

To follow the repository's strict file versioning rules, we have verified that a separate, uniquely timestamped markdown file is created in the `Prompts` directory for each prompt session.

## Rules Applied
- Every distinct user prompt session results in a new Markdown file (`.md`) inside the `Prompts` folder.
- Filenames are formatted as `yyyyMMdd.hhmmss_topic_description.md` based on the session's active timestamp.
- The user's exact prompt is placed at the very top of each generated document.
