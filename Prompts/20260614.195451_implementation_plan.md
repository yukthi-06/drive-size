# Implementation Plan - Change App Color Palette to Blue on White

This plan changes the application's visual style from a high-contrast Black-and-White theme to a modern, professional Blue-on-White theme by replacing black font, borders, and asset fills with a solid deep blue color (#0D47A1).

## Proposed Changes

### Android Theme Resources

#### [MODIFY] [colors.xml](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/Drive_Size_APK_GITHUB/app/src/main/res/values/colors.xml)
- Change all occurrences of `#000000` (black) to `#0D47A1` (deep blue).
- Update the custom `colorUsed` from `#000000` to `#0D47A1`.

#### [MODIFY] [dashboard_card_gradient.xml](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/Drive_Size_APK_GITHUB/app/src/main/res/drawable/dashboard_card_gradient.xml)
- Change stroke color from `#000000` to `@color/primary`.

### Vector Drawables

Change base fill colors (`#FF000000`) to `#FF0D47A1` in the following files:
- `ic_share.xml`
- `ic_settings.xml`
- `ic_search.xml`
- `ic_refresh.xml`
- `ic_open.xml`
- `ic_folder.xml`
- `ic_file.xml`
- `ic_duplicates.xml`
- `ic_delete.xml`
- `ic_dashboard.xml`
- `ic_back.xml`
