Build a complete Android application in **Java (NOT Kotlin)** named **Drive Size Viewer** that analyzes device storage usage and helps users identify and delete large files and folders.

## Objective

Create a fast, modern Android storage analyzer similar to WinDirStat or DiskUsage. The app should scan internal storage, calculate folder sizes recursively, display the largest folders and files, and allow users to delete unwanted files directly from the app.

## Technical Requirements

### Platform

* Android Studio (latest stable version)
* Java only (no Kotlin)
* Minimum SDK: 26
* Target SDK: Latest stable
* Material Design 3 UI
* MVVM architecture
* AndroidX libraries
* RecyclerView for lists
* Room database for caching scan results
* Background scanning using WorkManager or ExecutorService
* Runtime permission handling
* Support scoped storage requirements for Android 11+

---

## Core Features

### 1. Storage Scanner

Implement a recursive storage scanner that:

* Scans internal storage
* Calculates total size of every folder
* Calculates size of all files
* Aggregates child folder sizes into parent folders
* Skips inaccessible/system-protected directories gracefully
* Runs on a background thread
* Shows scan progress

Store scan results in memory and Room database.

Each scan result should contain:

* Full path
* Folder/File name
* Size in bytes
* Human readable size
* Last modified date
* File count
* Folder count
* Type (file/folder)

---

### 2. Largest Folders View

Create a screen showing:

Title: Largest Folders

Columns:

* Folder name
* Full path
* Size
* Number of files
* Percentage of total storage

Features:

* Sort descending by size
* Search folders
* Pull to refresh
* Tap folder to open details

Display top folders first:
Example:

1. Downloads – 12.4 GB
2. Movies – 9.8 GB
3. WhatsApp – 8.2 GB
4. DCIM – 7.5 GB

Features:

* Sort by size descending

* Delete selected files

## How to Build and Run the App

1. Open the project directory (`Drive_Size_APK_GITHUB`) in **Android Studio (latest stable version)**.
2. Let Gradle sync download all dependencies (Room, Lifecycle, Navigation Component, WorkManager).
3. Connect your Android device or start an emulator.
4. Press **Run** (Green Arrow) to build and deploy the app.
5. Grant the required storage permissions (All Files Access on Android 11+; Read/Write Storage on Android 10 and below).
6. Perform your first Scan from the dashboard!
